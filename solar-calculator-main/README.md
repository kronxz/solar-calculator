# ☀️ Simulador Solar - MF Soluções Elétricas

Simulador inteligente de sistemas fotovoltaicos desenvolvido para geração de propostas comerciais rápidas, precisas e profissionais.

🔗 Acesse o simulador:
https://kronxz.github.io/solar-calculator/

---

## 🎯 Objetivo

Este projeto foi criado para:

✔ Captar leads qualificados  
✔ Gerar simulações instantâneas  
✔ Apresentar propostas comerciais automatizadas  
✔ Aumentar conversão de vendas em energia solar  

---

## ⚡ Funcionalidades

- 📊 Cálculo automático de geração mensal (kWh)
- 💰 Estimativa de economia mensal, anual e em 25 anos
- 📦 Dimensionamento automático do sistema (kWp)
- 🔧 Sugestão de inversor conforme potência
- ☀️ Ajuste de perdas realistas (80%)
- 📍 Integração com Google Maps para visualização do telhado
- 📲 Envio automático de lead via WhatsApp
- 🧠 Sugestão de expansão futura do sistema
- 🔋 Seleção de potência dos módulos (450W / 550W / 620W / 700W /750W)

---

## 📐 Base Técnica

O simulador utiliza parâmetros reais de engenharia:

- HSP (Horas de Sol Pleno) por cidade
- Fator de perdas: **0.80**
- Geração:
  
  `kWp × HSP × 30 × perdas`

- Economia limitada a:
  
  `até 90% da conta de luz`

- Dimensionamento baseado no consumo real do cliente
